How assumptions get tested

Deck hypotheses (Questions slide):

H1 Flaky-flagged tests hide real regressions
H2 The flaky label is effectively permanent
H3 Lifecycle has more signal than segmentation
H4 Customers are hand-building the lifecycle
H5 The detection definition is too narrow

Supporting checks (not on the deck):

C1 Pull D's actual run: did the test pass on retry (the rule hid it) or fail outright (a developer trusted the stale label)?
C2 Telemetry audit with Cloud engineers: per-attempt data, retention, retry data
C3 Sample 30 days of flaky failures: how often error messages are generic timeouts vs distinct
C4 Where merge decisions and notifications land: usage analytics plus interviews
